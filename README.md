# ps1dev.github.io

The landing page for the ps1dev browser tools, served at <https://tools.psx.dev/>.

It is one static `index.html` with no build step: GitHub Pages serves this branch as-is.
The tools it links to live in their own repositories and deploy to their own paths under
the same domain, so adding one here means adding a list entry and nothing else.

| Tool | Repository |
| --- | --- |
| [timweb](https://tools.psx.dev/timweb/) | [ps1dev/timweb](https://github.com/ps1dev/timweb) |
| [loopy](https://tools.psx.dev/loopy/) | [ps1dev/loopy](https://github.com/ps1dev/loopy) |
